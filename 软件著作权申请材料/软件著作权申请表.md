## 二、软件开发情况

### 1. 开发背景

随着人工智能和计算机视觉技术的发展，皮肤健康分析领域需要更加智能化、便捷化的解决方案。传统的皮肤检测设备价格昂贵、操作复杂，普通消费者无法便捷使用。

本系统旨在通过Web端AI技术，为普通消费者提供专业级的皮肤健康分析服务，让用户在家就能了解自己的皮肤状况，并获得个性化的护肤建议。

### 2. 开发目的

- 将专业皮肤分析技术普及化、平民化
- 为消费者提供便捷的皮肤健康评估工具
- 基于AI的个性化护肤方案推荐
- 连接用户与护肤产品，提供智能导购服务

### 3. 主要功能

- 10维度量化面部分析（水油平衡、色斑、皱纹等10个维度）
- 高精度面部检测（68点/468点）
- 区域级热力图可视化
- 环境感知的动态护肤推荐（结合UV指数、湿度、空气质量）
- AM/PM护肤流程生成
- 产品智能推荐与导购
- 用户会话追踪与数据分析
- 护肤方案收藏与管理
- Web端本地化运行，保护用户隐私

### 4. 技术特点

- 基于MySkin.Technology专业皮肤分析标准的10维度量化评估
- 使用face-api.js和MediaPipe Face Mesh进行高精度面部检测
- 多AI供应商切换（Qwen/Jimeng），提高可用性
- 环境感知算法，结合实时天气数据动态调整护肤建议
- 基于LDAP（Local-first Architecture）的数据存储策略
- Web端本地化运行，保护用户隐私

### 5. 运行环境

#### 5.1 硬件环境
- CPU：Intel Core i5或同级及以上
- 内存：4GB RAM或以上
- 摄像头：720p或以上分辨率
- 存储：至少1GB可用空间

#### 5.2 软件环境
- 操作系统：Windows 10+ / macOS 10.15+ / iOS 14+ / Android 10+
- 浏览器：Chrome 90+ / Safari 14+ / Edge 90+
- 网络：稳定互联网连接，推荐带宽不低于10Mbps
  特殊说明：AI分析功能需要互联网，但用户可优先选择离线模式基于本地MediaPipe处理
