#### 4.2.3 面部扫描
**路径**：`/face-scan`  
**说明**：拍摄4张标准面部照片供AI分析

**四种角度**：

| 角度 | 姿势 | 说明 | 预计时间 |
|------|------|------|---------|
| 正脸 | 面对镜头，视线平视 | 拍摄正面完整面部 | 5-10秒 |
| 左脸 | 向左转45度 | 拍摄左侧轮廓 | 5-10秒 |
| 右脸 | 向右转45度 | 拍摄右侧轮廓 | 5-10秒 |
| 下颌 | 微微抬头，镜头仰拍 | 拍摄下颌线 | 5-10秒 |

**功能特性**：

##### ① 光线检测
系统自动评估拍摄环境光线质量：
- [√] **优秀**：光线充足均匀
- [√] **良好**：光线基本满足
- [!] **不足**：建议靠近窗户
- [X] **过暗**：需要补光
- [X] **过亮**：避免直射阳光

##### ② 面部检测
使用face-api.js实时检测：
- [√] 检测到面部 -> 出现绿色框
- [!] 面部不稳定 -> 进度条等待
- [X] 未检测到 -> 提示调整姿势

##### ③ 自动拍照
满足以下条件自动拍摄：
- 检测到稳定面部 ≥3秒
- 光线评分 ≥60分
- 姿势符合要求

##### ④ 手动拍照
若自动拍照失败，点击"手动拍照"按钮：
```
面部对准绿色框 → 点击"拍照"按钮 → 确认
```

##### ⑤ 语音引导
系统自动播放语音：
```
"请正对镜头"
"请向左转头"
"请向右转头"
"请微微抬头"
"光线良好，保持稳定..."
```

**操作步骤**：

```
1. 开始扫描
   |
2. 允许摄像头访问
   |
3. 首页引导弹窗
   - 阅读拍照要求
   - 点击"开始拍摄"
   |
4. 正脸拍摄
   - 根据语音引导调整姿势
   - 等待自动拍照 or 手动点击
   - 通过后进入下一角度
   |
5. 左脸拍摄
   - 向左转45度
   - 重复上述步骤
   |
6. 右脸拍摄
   - 向右转45度
   - 重复上述步骤
   |
7. 下颌拍摄
   - 微微抬头，镜头仰拍
   - 重复上述步骤
   |
8. 所有角度完成
   - 显示"拍摄完成"
   - 系统自动跳转到结果页
```

**常见问题**：

| 问题 | 解决方法 |
|------|---------|
| 拍摄失败 | 检查摄像头权限 |
| 面部检测不到 | 确保面孔完整在框内 |
| 光线不足 | 移到窗户旁或打开灯光 |
| 图片模糊 | 保持手稳，避免抖动 |

## 5. 常见问题

### 5.1 关于分析

**Q1: 分析结果准确吗？**  
A: 系统基于MySkin.Technology专业皮肤分析标准设计，结合AI深度学习模型，准确率可达90%以上。但仅供参考，不能替代专业皮肤科医生诊断。

**Q2: 为什么分析结果和我感受不一样？**  
A: AI分析基于图像特征，可能存在偏差。建议多次分析取平均值，或预约专业皮肤检测。

**Q3: 分析需要多久？**  
A: 通常10-30秒。如果AI服务器繁忙，可能需要1-2分钟。

**Q4: 分析结果保存多久？**  
A: 免费用户30天，VIP用户永久保存。

---

### 5.2 关于拍照

**Q5: 拍摄照片有什么要求？**  
A: 
- 光线充足但不刺眼
- 背景简洁纯色（白墙最佳）
- 移除口罩、墨镜、发帘
- 面部正对镜头，睁开双眼

**Q6: 可以环形象素要求？**  
A: 720p即可，1080p效果更佳。

**Q7: 拍照失败怎么办？**  
A:
- 检查摄像头权限
- 调整光线
- 保持手稳
- 手动拍照

---

### 5.3 关于隐私

**Q8: 我的照片会被上传吗？**  
A: 所有面部照片仅在本地处理，不会上传服务器。服务器只保存分析后的匿名数据。

**Q9: 数据安全吗？**  
A: 
- IP地址SHA-256哈希化
- 30天自动清理
- 支持一键删除

**Q10: 可以删除我的数据吗？**  
A: 可以。在"设置"中点击"删除我的数据"。
