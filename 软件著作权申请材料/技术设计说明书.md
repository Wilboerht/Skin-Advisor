## 1. 系统概述

### 1.1 系统定位

旎柏AI护肤顾问系统是一个面向消费者的智能皮肤健康分析平台，旨在通过人工智能技术提供：

- **专业级皮肤评估**：基于VISIA临床标准的12维度量化分析
- **个性化护肤方案**：结合肤质、关注点、环境的动态推荐
- **智能产品导购**：精准匹配用户需求的产品推荐

### 1.2 系统目标

| 目标 | 指标 |
|------|------|
| 首屏加载时间 | < 2秒 |
| AI分析准确率 | > 90% |
| 面部检测精度 | 68点/468点 |
| 用户满意度 | > 85% |

### 1.3 技术选型

| 层级 | 技术栈 | 选型理由 |
|------|--------|---------|
| 前端框架 | Next.js 16 | App Router、SSR、性能优化 |
| 前端库 | React 19 | hooks、并发渲染 |
| 样式方案 | TailwindCSS | 实用优先、定制方便 |
| 动画库 | Framer Motion | 流畅动画、无缝过渡 |
| 状态管理 | React Context | 简单场景足够 |
| ORM | Prisma | 类型安全、开发效率 |
| 数据库 | PostgreSQL | 生产环境 |
| 数据库(dev) | SQLite | 开发便利 |
| AI API | OpenAI/Qwen/Claude | 多供应商、高可用 |
| CDN | Vercel | 边缘计算、低延迟 |

**颜色映射算法**：

function scoreToHSL(score: number): string {
  // 0分：深红色（警告）
  // 50分：黄色（中等）
  // 100分：深绿色（健康）
  
  const hue = 120 - (score / 100) * 120; // 120→0
  const saturation = 80;
  const lightness = 50;
  
  return `hsl(${hue}, ${saturation}%, ${lightness}%)`;
}
```

interface MatchRule {

  operator: 'equals' | 'contains' | 'in';
  value: any;         // 匹配值
  weight: number;     // 权重
}

// 示例规则
const rules: MatchRule[] = [
  { field: 'suitableFor', operator: 'contains', value: 'dry', weight: 1.5 },
  { field: 'benefits', operator: 'contains', value: 'moisturizing', weight: 1.2 },
  { field: 'price', operator: 'in', value: [100, 200, 300], weight: 1.0 },
  { field: 'category', operator: 'equals', value: 'cleanser', weight: 0.8 },

```

**评分计算**：

```typescript
function calculateScore(product: Product, userProfile: UserProfile): number {
  let score = 0;
  
  // 肤质匹配
  if (product.suitableFor.includes(userProfile.skinType)) {
    score += 30;
  }
  
  // 功效匹配
  userProfile.concerns.forEach(concern => {
    if (product.benefits.includes(concern)) {
      score += 20;
    }
  });
  
  // 预算匹配
  if (userProfile.budget.min <= product.price && 
      product.price <= userProfile.budget.max) {
    score += 25;
  }
  
  // 非过敏成分
  if (!userProfile.allergies.some(allergy => 
      product.ingredients.includes(allergy))) {
    score += 25;
  }
  
  return score; // 0-100
}
```

function detectFaceStability(face: FaceDetection): boolean {
  const x = face.box.x;
  const y = face.box.y;
  const width = face.box.width;
  
  // 检测位置是否稳定（移动幅度<阈值）
  if (lastFacePosition) {
    const dx = Math.abs(x - lastFacePosition.x);
    const dy = Math.abs(y - lastFacePosition.y);
    const dWidth = Math.abs(width - lastFacePosition.width);
    
    if (dx < 10 && dy < 10 && dWidth < 5) {
      return true; // 稳定
    }
  }
  
  lastFacePosition = { x, y, width };
  return false;
}

## 5. 安全设计

### 5.1 隐私保护

#### 5.1.1 IP地址哈希化

```typescript
// src/lib/privacy.ts
import { createHash } from 'crypto';

export function hashIP(ip: string): string {
  const salt = process.env.IP_HASH_SALT || 'myskin-advisor-ip-salt';
  return createHash('sha256')
    .update(`${salt}:${ip}`)
    .digest('hex')
    .substring(0, 16); // 16字符足够唯一性
}
```

**特性**：
-不可逆：SHA-256哈希无法反向解密
-加盐：防止彩虹表攻击
-截断：16字符足够去重，不足10^24种可能

// middleware.ts
import { verify } from 'jsonwebtoken';

export function verifyToken(req: Request) {
  const authHeader = req.headers.get('authorization');
  const token = authHeader?.split(' ')[1];
  
  if (!token) {
    return null;
  }
  
  try {
    const decoded = verify(token, process.env.JWT_SECRET!);
    return decoded;
  } catch (e) {
    return null;
  }
}

import Redis from 'ioredis';

const redis = new Redis(process.env.REDIS_URL);

export async function getCached<T>(
  key: string,
  fetcher: () => Promise<T>,
  ttl: number = 3600
): Promise<T | null> {
  const cached = await redis.get(key);
  if (cached) {
    return JSON.parse(cached);
  }
  
  const data = await fetcher();
  await redis.set(key, JSON.stringify(data), 'EX', ttl);
  
  return data;
}

const providers: Record<string, AIVisionProvider> = {
  openai: new OpenAIVisionProvider(),
  qwen: new QwenVisionProvider(),
  anthropic: new AnthropicVisionProvider(),
};

export async function analyzeWithFallback(
  providerName: string,
  images: VisionImage[]
): Promise<FaceAnalysisResult> {
  let lastError: Error | null = null;
  
  // 尝试指定provider
  try {
    return await providers[providerName].analyzeImages(images);
  } catch (e) {
    lastError = e;
  }
  
  // 降级到备用provider
  for (const [name, provider] of Object.entries(providers)) {
    if (name !== providerName) {
      try {
        return await provider.analyzeImages(images);
      } catch (e) {
        lastError = e;
      }
    }
  }
  
  throw lastError;
}
